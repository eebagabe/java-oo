# Instruções:

Crie a classe Produto com os atributos privados nome, preco e quantidade. Faça um
construtor que receba os três. Crie os métodos adicionarEstoque(int qtd),
removerEstoque(int qtd) (não pode deixar o estoque negativo) e
valorTotalEmEstoque(). O preço nunca pode ser negativo. Teste no main com três
produtos.
